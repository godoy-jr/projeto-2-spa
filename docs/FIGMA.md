# Prototipação no Figma

## Arquivo do projeto

[Câmbio Fácil no Figma](https://www.figma.com/design/uX1l7OXMaKBnelFgvZ7ymi)

O link acima identifica o arquivo real de design do projeto Câmbio Fácil. A existência e o conteúdo descritos neste documento foram confirmados pelo responsável do projeto.

Outro assistente desta mesma colaboração conferiu o arquivo por meio da integração do Figma. Essa inspeção confirmou a estrutura de camadas editáveis, as versões desktop e mobile e suas prévias visuais. Este registro apenas consolida a evidência produzida por esse assistente e não atribui a inspeção ao responsável por esta atualização documental.

## Layouts produzidos

O arquivo contém layouts editáveis criados para o Câmbio Fácil com auxílio de inteligência artificial:

- wireframe de baixa fidelidade para desktop;
- wireframe de baixa fidelidade para mobile;
- protótipo de média fidelidade para desktop;
- protótipo de média fidelidade para mobile;
- estados de sucesso;
- estados de carregamento;
- estados de erro;
- estados de ausência de dados;
- estados de validação.

## Limitações atuais

- os layouts são estáticos;
- ainda não há navegação ou conexões interativas entre os frames;
- o arquivo não comprova o funcionamento da aplicação;
- a implementação ainda deve ser comparada aos protótipos durante as próximas etapas;
- a navegação interativa entre os frames ainda precisa ser criada e conferida.

## Referências do professor

As sugestões denominadas **HERMES**, apresentadas pelo professor no Notion, foram usadas apenas como referências de wireframe e direção visual. Elas não são trabalho autoral do projeto e não devem ser apresentadas como protótipos do Câmbio Fácil.

Os layouts do link acima pertencem ao projeto Câmbio Fácil e foram produzidos separadamente, tomando os requisitos documentados como base. Elementos presentes nas referências HERMES que não fazem parte dos requisitos confirmados, como idiomas adicionais, não foram adotados como novas funcionalidades.
